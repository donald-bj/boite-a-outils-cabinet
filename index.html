PDF vers Excel

Récupérez le tableau d’un PDF dans un fichier Excel, sans le ressaisir. Déposez le document, le reste se fait tout seul.

Votre document reste sur votre ordinateur Aucun compte à créer Gratuit et sans limite

Choisissez votre PDF

L’outil retrouve les colonnes du tableau et crée une feuille Excel par page du document.

Réglages

Commencez par choisir un fichier.

Comment ça marche

1

Vous déposez votre PDF. Il est lu directement par votre navigateur, il ne part nulle part.

2

L’outil retrouve les colonnes. Un aperçu des premières lignes s’affiche pour que vous vérifiiez avant de télécharger.

3

Vous récupérez le classeur. Une feuille par page, prête à ouvrir dans Excel.

Bon à savoir

  • Un PDF scanné ne contient qu’une image, pas du texte : l’outil vous préviendra que la page ressort vide. Il faut d’abord lui appliquer une reconnaissance de caractères.
  • Vérifiez toujours l’aperçu avant de télécharger. Les tableaux sans quadrillage et les cellules fusionnées restent les cas les plus délicats.
  • Deux tableaux côte à côte sur une même page ressortent mélangés sur les mêmes lignes : les données sont là, mais il faut séparer les colonnes dans Excel.
  • Les en-têtes et pieds de page du document se retrouvent dans le classeur : il suffit de supprimer ces lignes dans Excel.
  • Rien n’est envoyé sur Internet. Le document reste sur votre ordinateur du début à la fin.
  • Les documents du cabinet restent soumis à la charte d’usage de l’IA, y compris le fichier obtenu ici.
